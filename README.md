# EnDML

# Efficient and Effective Calibration of Numerical Model Outputs Using Hierarchical Dynamic Models

Ensemble double/debiased machine learning for binary exposure and outcome variables to assess heterogeneous Long COVID risk associated with preexisting comorbidities.

This Github page provides code and simulated data for reproducing the results in the manuscript: Chen Y, Chen Z, Yang G, et al. [Comorbidity Exposure-Window Definitions and Multidimensional Disparities in Long COVID Risk: Evidence from a US National Cohort (2020-2024)](https://www.medrxiv.org/content/10.64898/2026.07.11.26357794v1). medRxiv, 2026: 2026.07. 11.26357794.
